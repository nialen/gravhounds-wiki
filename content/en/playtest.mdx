<h2 id="steps">How to request GRAVHOUNDS playtest access</h2>

1. Sign in to the Steam account you want to use for testing.
2. Open the official [GRAVHOUNDS Steam page](https://store.steampowered.com/app/2440760/).
3. Find the **Join the GRAVHOUNDS Playtest** section.
4. Select **Request Access** if the control is available.
5. Confirm the request and wait for Steam to notify you if access is granted.

This is the only public application flow confirmed in the reviewed sources. The separate playtest record is Steam App 4586390, but players should begin from the main official store page rather than attempting to launch database links.

<h2 id="after">What happens after you apply?</h2>

Requesting access places the account in the Steam Playtest applicant pool. Steam says applicants are notified when the developer is ready to add more participants. A request is not a reservation for immediate access and does not prove that a testing wave is active.

The reviewed material does not publish wave dates, participant counts, region limits, progress carryover or a non-disclosure agreement. Any invitation should be read carefully for current conditions.

<StatusCallout title="Access is not guaranteed">

There is no confirmed public invite code. Request Access can remain pending, and the developer controls when additional testers are admitted.

</StatusCallout>

<h2 id="safety">Avoid fake playtest keys</h2>

Use the Steam store and official GRAVHOUNDS channels. Do not pay a third party for an alleged test key, share a Steam login or install an executable delivered through an unsolicited message. Steam Playtest access is normally attached to the approved account.

SteamDB is useful for confirming that a separate app record exists, but it is an independent database. Its history page cannot tell a player that applications are currently being accepted or how many spaces remain.

<h2 id="prepare">Prepare your PC</h2>

Before a possible invitation, compare your system with the [official PC requirements](/en/system-requirements/). The current minimum lists Windows 10, 8 GB RAM, DirectX 12 and 10 GB of available storage. Requirements and test builds can change, so the invitation and Steam page remain authoritative at installation time.
